## 1. 项目概述

### 1.1 定位

DocScanX 是一个**文档敏感信息扫描系统**，采用**两期演进**策略：

- **一期（纯离线）**：面向内网纯离线环境，搭载私有 UIE 模型 + PaddleOCR 引擎，批量扫描本地目录下的各类办公文档，自动提取个人敏感信息（姓名、身份证号、手机号、地址等），跨文件关联同人数据，完成脱敏处理后输出结构化报告。
- **二期（智能增强）**：对接企业已建设的大模型，对 PDF 扫描件、图片等非文本文件进行深度识别；同时扩展支持远程文件服务器（FTP、SFTP、CIFS、SMB），在更大范围内覆盖组织的个人信息保护合规义务。

### 1.2 核心目标

1. **批量扫描** — 支持千级文件批量扫描，覆盖常见办公文档、PDF、图片等格式
2. **敏感信息提取** — 基于 UIE 模型 + 规则引擎，精准提取 10+ 类个人敏感字段
3. **跨文件关联** — 同一自然人在不同文档中出现，自动关联聚合
4. **合规脱敏** — 输出前对敏感字段自动脱敏，支持掩码模式
5. **多格式报告** — 输出 JSON / Excel / HTML / CSV 四种报告格式
6. **纯离线运行（一期）** — 无需联网、无需 GPU、无数据外传风险

### 1.3 硬性约束

| 约束项 | 要求 |
|--------|------|
| 网络环境（一期） | 完全离线，部署后不可联网 |
| 网络环境（二期） | 可选内网连接大模型 API 及远程文件服务器 |
| 硬件（一期） | CPU 推理，不支持 GPU |
| 硬件（二期） | CPU/GPU 均可（依赖大模型部署方式） |
| 数据安全 | 扫描数据不出域，不上传公网第三方服务 |
| 部署方式 | 支持源码部署 + 单文件绿色部署（Windows .exe / Linux 可执行文件） |
| 操作系统 | Windows 10/11 x64 + Linux（Ubuntu 20.04+, CentOS 7+, 或其他兼容内核） |
| 第三方依赖（一期） | 不可调用在线 API（如 OCR 云服务） |
| 第三方依赖（二期） | 支持调用内网大模型 API（如企业内部 LLM 平台） |

### 1.4 二期规划

DocScanX 一期是纯离线私有模型方案，二期在此基础上做**两个方向的扩展**：

#### 1.4.1 大模型对接（面向非文本文件）

企业客户内部已建设大模型平台，二期支持对接内网大模型 API：

| 场景 | 一期方案 | 二期大模型增强 |
|------|----------|---------------|
| PDF 扫描件 | PaddleOCR + UIE | 大模型直接理解版面 + 抽取结构化字段 |
| 图片文字 | PaddleOCR 文字识别 | 大模型端到端图文理解 |
| 复杂表格 | OCR + 规则解析 | 大模型还原表格结构 |
| 非中文文档 | 不支持 | 大模型多语言抽取 |

**对接方式**：
- 通过 REST API 调用企业内部 LLM 服务
- 支持 OpenAI 兼容格式（兼容主流大模型网关）
- 大模型结果与 UIE 结果做交叉验证，提升置信度
- 支持私有化部署的 LLM（如 ChatGLM、Qwen、百川等）

#### 1.4.2 远程文件源接入

扩展文件来源，支持直接扫描远程文件服务器：

| 协议 | 描述 | 支持操作 |
|------|------|----------|
| FTP | 标准文件传输协议 | 目录浏览、文件下载 |
| SFTP | SSH 加密文件传输 | 目录浏览、文件下载 |
| CIFS | Windows 网络共享 | 目录浏览、文件下载（直接或通过挂载） |
| SMB | 通用网络共享协议 | 目录浏览、文件下载（直接或通过挂载） |

**远程接入规范**：
- 连接凭据存储在配置文件中，支持加密存储
- 支持连接测试按钮（前端提供）
- 支持断线重试机制
- 文件流式下载，不占用本地磁盘缓存
- 支持远程路径与本地路径混合扫描

### 3.1 工作台（Dashboard）

**F1 统计概览卡片**
- 扫描文件总数
- 数据主体总数
- 敏感字段总数
- 文件成功率

<font color="gray">*注：此为全平台统计，非单任务统计。单任务统计详见扫描报告页面。*</font>

**F2 快捷扫描入口**
- 快速选择目录/文件，使用默认配置立即启动扫描
- 点击后跳转到扫描任务页面，预填参数后可调整再启动

**F3 最近任务列表**
- 最近 5 条扫描任务记录
- 每项显示：任务名称、文件数、状态、扫描时间
- 支持点击跳转到任务对应报告
- 右上角"查看全部"跳转到扫描任务列表

### 3.2 扫描任务页面

**F4 扫描任务列表**
- 默认页，展示所有扫描任务的历史列表
- 每项显示：任务名称、扫描类型、目标路径、文件数、数据主体数、状态、创建时间
- 支持按状态、时间范围筛选
- 支持关键词搜索（任务名称/路径）
- 分页显示（默认每页 20 条）
- 点击任务行可跳转到扫描报告查看详情
- 支持删除历史任务记录
- 支持重新执行历史任务

**F5 新建扫描任务（向导）**
- 点击"新建任务"按钮，进入向导式创建流程
- 第一步：选择扫描类型
- 后续步骤根据所选类型动态变化
- 支持"取消"返回列表

**F6 单文件扫描向导**
- 步骤 1：选择目标文件（文件选择器）
- 步骤 2：配置扫描参数：
  - 脱敏开关
  - OCR 引擎选择
  - UIE 模型选择
  - 实体置信度阈值
  - 文本分片阈值
- 步骤 3：确认启动

**F7 文件目录扫描向导**
- 步骤 1：选择目标文件夹（目录树浏览或路径输入）
  - 包含子目录复选框
  - 解压压缩包复选框
  - 文件数预估显示
- 步骤 2：文件后缀筛选：
  - 分组勾选：压缩包类、新式办公文档类、老旧二进制文档类、图片类、文本类、开发类
  - 全选/全不选快捷按钮
- 步骤 3：配置扫描参数（同 F6 步骤 2）
- 步骤 4：确认启动

**F8 文件服务器扫描向导（二期）**
- 步骤 1：配置服务器连接（协议、地址、端口、凭据）
- 步骤 2：选择远程路径
- 步骤 3：文件后缀筛选
- 步骤 4：配置扫描参数
- 步骤 5：确认启动

---

**关于扫描过程中的状态监控**：扫描进度、实时日志、结果预览统一在扫描报告页面中查看，扫描任务启动后自动跳转到报告页面。

### 3.3 数据主体页面

**F9 数据主体列表**
- 表格展示所有数据主体：
  - 序号、姓名（脱敏）、身份证（脱敏）、手机号（脱敏）
  - 风险等级标签（低/中/高/极高，不同颜色）
  - 置信度分值
  - 信息完整度（1-5星）
  - 来源文件数
- 分页显示（默认每页 20 条）

**F10 筛选与搜索**
- 按风险等级过滤
- 按置信度区间过滤
- 按信息完整度过滤
- 按来源文件类型过滤
- 关键词搜索（姓名/证件号/文件路径）

**F11 主体详情弹窗**
- 点击单一数据主体后弹出的完整档案视图：
  - 主标识（身份证/手机号/姓名三选一，标注类型）
  - 所有标识字段（已脱敏）
  - 证据链：每条信息的来源文件、段落位置
  - 关联文件列表
  - 数据质量告警（如：信息不完整、置信度偏低、身份证重复等）

### 3.4 扫描报告页面

**F12 统计概览卡片**
- 选定任务的统计摘要：
  - 扫描文件总数
  - 数据主体总数
  - 敏感字段总数
  - 文件成功率
- 首次进入页面时提示选择任务

**F13 风险分布图表**
- 按风险等级分布的环形图或柱状图
- 可选按文件类型、按来源目录的维度

**F14 异常文件统计**
- 失败文件数 + 失败率
- 失败原因分布（格式不支持、文件损坏、加密、读取超时）
- 格式分布

**F15 导出按钮组**
- [导出 JSON] — 完整结构化数据
- [导出 Excel] — 多 Sheet（汇总 + 人员清单 + 异常文件）
- [导出 HTML 报告] — 浏览器可查看的完整报告
- [导出失败清单 CSV] — 异常文件清单
- [打开输出目录] — 直接打开文件管理器

> **历史报告**：不再独立列出，历史任务列表集成在扫描任务页面中，从扫描任务列表点击任务行可跳转至此页面查看对应报告。

### 3.5 系统设置页面

**F16 通用配置**
- 脱敏开关
- 开发类文件抽取开关
- 实体置信度阈值
- 文本分片阈值（字符数，默认 512）

**F17 OCR引擎管理**
- OCR 引擎选择（二选一）：
  - **RapidOCR（默认）** — 优先使用 RapidOCR，若单页置信度低于阈值（默认 0.6）自动降级到 PaddleOCR，后台日志记录降级事件
  - **PaddleOCR** — 固定使用 PaddleOCR V4 Lite，不调用 RapidOCR
- 各引擎路径配置
- 模型存在/缺失状态指示

**F18 UIE模型管理**
- 模型版本切换（tiny / small / base）
- 路径配置
- 模型存在/缺失状态

**F19 资源限制**
- 内存上限（MB，默认 2048）
- OCR线程数（默认 1）
- UIE线程数（默认 1）
- 单文件处理超时（秒，默认 300）

**F20 日志配置**
- 日志级别（DEBUG / INFO / WARNING / ERROR）
- 日志保留天数（默认 7）
- 单日志文件上限（MB，默认 10）

**F21 路径配置**
- 输出目录
- 临时目录
- 模型目录

### 3.6 系统日志页面

**F22 操作审计日志**
- 系统关键操作记录：启动、停止、配置变更、报告导出
- 每条包含：时间、操作类型、操作内容、结果
- 支持按时间范围筛选

**F23 文件处理轨迹**
- 每个文件的完整处理记录：
  - 文件路径 → 格式判定 → PDF/文本判定 → 提取字段数 → 最终状态（成功/失败/部分成功）
  - 失败时记录失败阶段和原因

**F24 日志筛选与搜索**
- 按日志级别过滤（DEBUG / INFO / WARNING / ERROR）
- 按日志类型过滤（system / task / audit）
- 按时间范围筛选
- 关键词搜索
- 分页显示（默认每页 20 条）

## 4. 支持的文件类型

| 类别 | 格式 | 默认选中 | 说明 |
|------|------|----------|------|
| 压缩包 | `.zip` `.rar` `.7z` | ✅ 是 | 自动解压后扫描内部文件 |
| 新式办公文档 | `.docx` `.xlsx` `.pptx` | ✅ 是 | OOXML 格式，python-pptx/openpyxl/docx 解析 |
| 老旧办公文档 | `.doc` `.xls` `.ppt` | ❌ 否 | 二进制格式，需额外兼容层 |
| PDF 文档 | `.pdf` | ✅ 是 | 支持文本 PDF + 扫描件 PDF |
| 图片 | `.jpg` `.png` `.bmp` `.tiff` | ✅ 是 | 仅含文字的图片，走 OCR 流程 |
| 文本文件 | `.txt` `.csv` `.md` `.log` | ✅ 是 | 纯文本直接读取 |
| 结构化数据 | `.json` `.xml` | ❌ 否 | 可选启用，抽取字段名匹配信息 |
| 代码文件 | `.py` `.java` `.js` `.html` `.sql` `.css` `.cpp` | ❌ 否 | 开发类文件，默认关闭 |

## 6. 非功能性需求

### 6.1 性能要求

| 指标 | 要求 |
|------|------|
| 单文件OCR识别 | ≤ 10s/页（PaddleOCR V4 Lite，CPU） |
| 单文件UIE抽取 | ≤ 3s/文件（平均） |
| 千级文件扫描 | 完整管道 ≤ 30min（混合文档类型） |
| 并发处理 | 支持多文件并行（文件解析 + OCR异步 + UIE异步） |

### 6.2 内存要求

| 场景 | 内存 |
|------|------|
| UIE-Small 模型加载 | ~500MB |
| PaddleOCR V4 Lite 加载 | ~800MB |
| 全面运行时 | ≤ 2GB |
| 闲置时 | ≤ 200MB |

### 6.3 磁盘占用

| 组件 | 大小 |
|------|------|
| UIE-Tiny | ~30MB |
| UIE-Small | ~100MB |
| UIE-Base | ~400MB |
| PaddleOCR V4 Lite | ~12MB |
| PaddleOCR NCNN | ~15MB |

### 6.4 兼容性

- Windows 10/11 x64 + Linux（Ubuntu 20.04+, CentOS 7+, 或其他兼容内核）
- Python 3.8+
